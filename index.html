GitHub Actions YAML Workflow:
name: Deploy ASP.NET to IIS Windows Server
Trigger: on: [push: main, pull_request]
📋 Checkout Code
📋 Setup .NET 8.0
📋 Restore NuGet - dotnet restore
📋 Build Solution - dotnet build -c Release
📋 Run Unit Tests - dotnet test
📋 Publish Release - dotnet publish -c Release -o ./publish
Deploy to IIS (SSH):
🔌 SSH Connect - appssh@ec2-windows-server.com
📤 SCP Upload Artifacts - Copy ./publish to C:\temp\deploy
⏹️ Stop App Pool - appcmd stop apppool /apppool:MajhiPaithani
💾 Create Backup - Compress-Archive -Path C:\inetpub\wwwroot\MajhiPaithani -DestinationPath C:\backups\backup_$(Get-Date -f yyyyMMdd_HHmmss).zip
📂 Copy Published Files - Copy-Item C:\temp\deploy\* -Destination C:\inetpub\wwwroot\MajhiPaithani -Recurse -Force
▶️ Start App Pool - appcmd start apppool /apppool:MajhiPaithani
✅ Health Check - curl https://majhipaithani.com/api/health -ErrorAction Stop

GitHub Actions YAML Workflow:
name: Build Docker Image & Deploy to EKS
Stage 1: Build Docker Image
📋 Checkout Code - actions/checkout@v4
📋 Setup Docker Buildx
📋 Build Dockerfile - docker build -t majhipaithani:${{ github.sha }} .
📋 Tag Image - majhipaithani:latest, majhipaithani:v1.0
Stage 2: Push to AWS ECR
🔐 AWS ECR Login - aws ecr get-login-password | docker login
📤 Push Image - docker push 123456789.dkr.ecr.us-east-1.amazonaws.com/majhipaithani:latest
📤 Push Tag Version - docker push ...majhipaithani:${{ github.sha }}
📝 Update Image URL in K8s manifest
Stage 3: Deploy to EKS Cluster
⚙️ Configure kubectl - aws eks update-kubeconfig --name production-cluster
📋 Apply Deployment - kubectl apply -f deployment.yaml
📋 Apply Service - kubectl apply -f service.yaml
📋 Patch Image Tag - kubectl set image deployment/majhipaithani majhipaithani=ECR_IMAGE_URL
🚀 Rollout Restart - kubectl rollout restart deployment/majhipaithani -n production
⏳ Wait for Ready - kubectl rollout status deployment/majhipaithani
Stage 4: Verify & Monitor
✅ Check Pod Status - kubectl get pods -o wide
✅ Check Service - kubectl get svc majhipaithani-service
✅ Health Check - curl https://api.majhipaithani.com/health
📊 Pod Logs - kubectl logs -l app=majhipaithani
📈 CloudWatch Metrics - Monitor CPU/Memory
🔄 HPA Status - kubectl get hpa majhipaithani-hpa
📄 Kubernetes Deployment YAML:
apiVersion: apps/v1
kind: Deployment
metadata:
name: majhipaithani-app
spec:
replicas: 3 # Auto-scaling
strategy: rolling updates
containers:
- image: aws_account.dkr.ecr.region.amazonaws.com/majhipaithani:latest
- imagePullPolicy: Always
- livenessProbe: /health
- readinessProbe: /ready
- resources: limits & requests
